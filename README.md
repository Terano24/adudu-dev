# Adudu Dev - Unified Agile Platform

Platform pengganti spreadsheet manual: Unified Agile Backlog, Dependency Board, dan DoD Gatekeeper.

## Struktur
```
docs/            Product backlog & catatan sprint
src/features/    backlog (S1), dependencies (S2), progress (S3), dod, auth
src/pages/       Halaman/route
src/components/  Komponen UI bersama
src/services/    Akses data/API
src/data/        Data sementara (JSON)
```

## Jalankan
```
npm install
npm run dev
```
